# 증빙 판독 파이프라인

시작하자마자 speciai_brief(domain: "skill_receipt")를 호출해 판독·검증 절차를 받고, 받은 절차를 그대로 따른다.

증빙 파일은 Read 도구로 직접 읽어 판독한다(별도 OCR 엔진 불필요). 공급자 사업자등록번호가 추출되면 speciai_biz_status로 실사업자 여부를 교차 검증한다.

키 미설정·한도 초과 시: 안내문 전달 후 기본 판독만 수행하고, 검증(사업자 조회·장부 연동)은 진행하지 않는다.
