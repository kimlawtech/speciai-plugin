# 사업계획서 생성 파이프라인

시작하자마자 speciai_brief(domain: "skill_bizplan")를 호출해 파이프라인 절차를 받고, 받은 절차를 그대로 따른다.

지침 수신 실패(키 미설정·한도 초과) 시: 실패 안내문을 사용자에게 그대로 전달하고, 파이프라인을 진행하지 않는다 — 검증 게이트 없는 사업계획서는 내보내지 않는 것이 원칙이다. 일반적인 PSST 목차 안내 정도만 제공한다.
