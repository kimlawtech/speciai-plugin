# 형사 의견서 파이프라인

시작하자마자 speciai_brief(domain: "skill_criminal")를 호출해 파이프라인 절차를 받고, 받은 절차를 그대로 따른다.

지침 수신이 402(pack_required)면: 변호사 에디션 전용 기능임을 안내하고 결제 링크를 그대로 보여준다. 파이프라인은 진행하지 않으며, 형사 의견서의 일반 구조(수사/공판 분기·항목 체계) 안내만 제공한다.

키 미설정·한도 초과 시: 안내문 전달 후 진행하지 않는다 — 검증 없는 형사서면은 내보내지 않는 것이 원칙이다.
